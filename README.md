# Projeto Integrador - Calculadora em Java

## 🎯 Objetivo
Desenvolver um projeto Java focado em **testes automatizados (unitários e funcionais)** e no **gerenciamento de código com GitHub**.  
O projeto aplica **JUnit 5** para garantir a qualidade do código e utiliza práticas de versionamento (branching e merge) para simular um fluxo de trabalho colaborativo.

### Objetivos específicos:
- Aplicar testes unitários e funcionais automatizados utilizando JUnit 5, com conceitos de verificação e validação de software.  
- Configurar e gerenciar um repositório Git, implementando práticas de branching e merge.  
- Simular o desenvolvimento colaborativo, aplicando boas práticas de controle de versão e qualidade de software.  

---

## ⚙️ Desenvolvimento
O módulo escolhido foi uma **Calculadora**, implementada com as quatro operações básicas:

- **Somar** → números positivos, negativos e zero.  
- **Subtrair** → números positivos, negativos e zero.  
- **Multiplicar** → números positivos, negativos e zero.  
- **Dividir** → números positivos, negativos e casos de divisão por zero (lançando exceção).  

Para cada funcionalidade, foram criados **testes unitários com JUnit 5**, cobrindo cenários de sucesso e falha.

---

## 📂 Estrutura do Projeto
- `src/br/com/projetointegrador/Calculadora.java` → Classe principal da calculadora.  
- `src/test/br/com/projetointegrador/CalculadoraTest.java` → Testes unitários com JUnit 5.  

---

## 🧪 Testes
Os testes garantem que todas as operações funcionem corretamente:  
- Soma de positivos, negativos e zero.  
- Subtração de diferentes casos.  
- Multiplicação de diferentes casos.  
- Divisão, incluindo tratamento de exceção ao dividir por zero.
